# no debe aparecer en buscadores ni ser citada por asistentes de IA.

# ⚠ POR QUÉ AQUÍ NO HAY "Disallow: /" PARA LOS BUSCADORES.
# Parece lo lógico, pero conseguiría lo contrario. Un "Disallow" no
# significa "no indexes": significa "no entres". Si Google no entra,
# nunca llega a leer la etiqueta <meta name="robots" content="noindex">
# de cada página, y si alguien enlaza la herramienta desde fuera, la URL
# puede acabar apareciendo igual en los resultados, sin título ni
# descripción, y sin forma limpia de quitarla.
#
# Lo correcto es al revés: se les DEJA entrar para que lean el noindex
# y retiren la página. Ese noindex está en las seis páginas del sitio y
# además se envía como cabecera X-Robots-Tag desde _headers.
#
# Con los bots de IA es distinto: no obedecen la etiqueta noindex, así
# que robots.txt es la única herramienta que hay para ellos. A esos sí
# se les cierra la puerta explícitamente.
# ===========================================================
